Box Key Check

Shows exactly which keys the iPad receives from the VoiceOver box, so we can tell a box problem from an iPad setting.

1. With VoiceOver off: what does the iPad receive?

Turn VoiceOver off. Tap the green box below, then turn the wheel one click and press each button on the box once.

Not listening yet: tap the green box.
  1. Nothing received yet.
Each line should name a button. In VoiceOver mode every line should show Control + Option + …, except Back (Escape) and Chooser (Command + W, then Command + H).
Nothing appears at all: the iPad isn't getting keys from the box (USB link or accessory setting).
Keys appear without Control + Option: the box is sending wrong keys. Tell Claude what the lines say.
All lines look right: the box is fine, and VoiceOver's key settings on this iPad are the problem.

2. With VoiceOver on: does it obey the box?

Turn VoiceOver on. Use the wheel to move through these four buttons, then press the big button. The one it lands on lights up and is added to the log above.
